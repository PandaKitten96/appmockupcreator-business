# AppMockupCreator Roadmap

## Phase 1: Validate demand (Weeks 1-4)
- Finalize positioning and homepage
- Build landing page and waitlist
- Build first mockup editor with templates
- Support core device frames
- Add PNG export
- Launch beta and gather feedback

## Phase 2: Product-market fit (Weeks 5-8)
- Improve template quality
- Add custom color system
- Add brand control and layout presets
- Save and load projects
- Improve onboarding and export flow
- Launch free and Pro plans

## Phase 3: Growth and retention (Weeks 9-12)
- Team plan
- Premium template packs
- Better export presets
- Analytics and funnel measurement
- Publish tutorial content and demo walkthroughs
- Collect testimonials and improvement requests

## Phase 4: Scale (Weeks 13+)
- Agency features
- White-label offering
- More device types and mockup categories
- User-generated showcase gallery
- Collaboration and shared asset library
- Expand beyond app mockups into related visual product storytelling

## Focus rule

Do not expand too early. Building the right core workflow is more important than stacking features too quickly.
