# AppMockupCreator MVP

This is the product MVP for AppMockupCreator.

## Goals

- Ship a high-value landing page
- Deliver a polished mockup editor shell
- Validate the user workflow quickly
- Prepare a legal and technical baseline before production scaling

## Included in this MVP

- Marketing homepage for AppMockupCreator
- Mockup editor canvas shell
- Pricing section
- Feature overview
- Basic accessibility and responsive layout
- Testing coverage for key UI elements

## Stack

- React
- Vite
- Vitest + Testing Library

## Scripts

```bash
npm install
npm run dev
npm run test
npm run build
```
